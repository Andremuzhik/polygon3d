# История изменений

Проект разрабатывался итерациями; здесь собрано главное по датам и темам.

## 2026-10-09
- Dependabot: версионные обновления отключены, чтобы не плодить pull request'ы. Уязвимости
  проверяет еженедельный workflow Security.
- Чистка: удалены неиспользуемые файлы и мёртвый код, убраны лишние комментарии. Бот без токена
  теперь завершается без ошибки и не перезапускается в цикле.

## 2026-10-08

### Сайт и кабинет
- Главная, услуги, портфолио с фильтром и пагинацией, отзывы, контакты, форма заявки с референсами.
- Регистрация, вход, восстановление пароля по email, личный кабинет с заказами и перепиской.
- **Сдача результата:** менеджер прикрепляет файлы в админке, клиент принимает работу или просит
  правки (счётчик правок относительно включённых в стоимость).
- **История заказа** (кто, что и когда) и письма клиенту о ключевых событиях.
- 3D-просмотр работ (`.glb`/`.gltf`), который подгружается по нажатию кнопки.
- SEO-основа: `sitemap.xml`, `robots.txt`, Open Graph, фавиконка, страницы 404 и 500.

### Админка
- Дашборд на главной (заказы по месяцам и статусам, средний срок, заказы без реакции).
- Выгрузка заказов в CSV с защитой от формульной инъекции.

### Telegram-бот
- Каталог услуг и портфолио, оформление заказа в диалоге, «Мои заказы», чат с менеджером.
- Уведомления менеджерам и клиентам, кнопки смены статуса, файлы результата и приёмка работы.
- Ограничение: не больше 5 заказов в час с одного аккаунта.

### Безопасность
- Ограничение частоты запросов, проверка загрузок по содержимому, CSP и Permissions-Policy.
- Версии зависимостей закреплены хешами.
- Workflow Security: CodeQL, pip-audit, Trivy по образу, gitleaks по истории.

### Инфраструктура и качество
- Docker (dev и production с Caddy), CI/CD на GitHub Actions: lint и тесты на PostgreSQL,
  smoke-тест образа, E2E в браузере (Playwright), публикация образа в GHCR.
- Проверка стиля: ruff и pycodestyle (PEP 8, лимит строки 100).
- 146 unit- и интеграционных тестов, 11 E2E-сценариев.
